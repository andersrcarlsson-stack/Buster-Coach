# fonts/

**BusterPieces.ttf**: the twelve chess piece glyphs (U+2654–U+265F) from **GNU FreeSerif** (GNU FreeFont,
2002–2012, the GNU FreeFont contributors), subset with fontTools and renamed "Buster Pieces" so the app can tell its
own copy from a system font (2026-10-20). Built into the program as a Qt resource (`resources.qrc`).
